# Documentation archive

Historical benchmark reports and retired API instructions are preserved here for
research provenance. They describe their original models, hardware, dependencies
and workflows; they are not instructions or performance expectations for the
current checkout. Some reports do not record enough detail to reproduce a run.

- `performance/`: recorded model benchmarks and historical quality/memory results.
- `fid/FID.md`: the FID workflow using scripts from the legacy branch.
- `developer/`: retired CogVideoX tutorial scripts; current integration guides use source walkthroughs.
- `legacy-apis.md`: the early API and legacy-branch notes from the project README.

This directory is excluded from the MkDocs build, navigation and search. Read it
in the repository when investigating historical results. Current instructions are
in the [runner guide](../runner/runner.md) and the generated
[CLI reference](../runner/cli.md).
